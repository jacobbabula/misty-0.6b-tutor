# Limitations and responsible-use boundary

1. **The model is small.** A 0.6B model can be fast enough for local use but has limited reasoning, instruction-following, multilingual consistency, and factual reliability.
2. **Local does not mean automatically safe.** On-device inference reduces network exposure; it does not eliminate unsafe or incorrect output.
3. **The evidence is bounded.** Passing contract tests and one authenticated browser acceptance do not establish general child safety, teaching quality, or fairness.
4. **Device behavior varies.** WebGPU support, memory pressure, caching, and latency differ across browsers and Chromebooks.
5. **Public examples are not transcripts.** Private family-session text is not published.
6. **No model authority.** The model must never grade, place, unlock, publish, authorize, or modify learner evidence.
7. **No silent cloud fallback.** If browser-local execution is unavailable, the product should say so rather than transmit the conversation elsewhere.
8. **No unrestricted deployment.** Independent privacy, security, child-safety, educational-quality, and representative-device review remain required.
